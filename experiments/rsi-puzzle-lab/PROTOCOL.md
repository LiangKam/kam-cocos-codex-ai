# RSI Puzzle Lab — 实验预注册

本目录为完全独立的实验；不改动原 Cocos 插件代码，不合并 main。

## 题目
八数码（3×3 数字滑块）求解 Agent 的受约束自改进。下一代继承当前通过验收的策略源码，并基于上一轮实测反馈生成候选；失败候选不接管。

## 不可变规则
- 目标状态：1 2 3 / 4 5 6 / 7 8 0。
- 每关最多 900 个有效节点扩展；所有版本一致。
- 每条路径须由独立验证器逐步重放，终局正确且步数等于独立 BFS oracle 给出的最优距离。
- 固定、互不重叠的训练集 128 关、验证集 256 关、最终保留集 512 关。
- 按最优距离分层取样（6–31 步）；固定种子 20260924。
- 选择顺序：无非法/非最优路径 > 通关数 > 固定预算下的平均有效扩展量。失败关按 900 扩展计费。
- 决策只使用训练/验证集；最终保留集仅在候选搜索结束后评估一次。允许一次性比较历史冠军，不允许据此再选新冠军。
- 所有候选、接受/拒绝理由、源码 SHA-256、父版本、耗时均留档；不强制每轮一定进步。
- 评估器、测试集与本协议冻结哈希；候选生成器只可改受限策略，不能改验收规则。

## 时间与诚实边界
目标为当前会话中实际执行超过 30 分钟的持续实验，时间取自运行器真实时钟；禁止 sleep 凑时长、伪造结果、把准备时间冒充自主迭代时间。

这是限定策略语法与工具集内的自改进工程演示，不声称基础模型权重被修改，不声称实现开放式 RSI。运行期间的自动候选来自本地程序搜索；对话模型负责搭建、检查与反馈驱动的工程改进。不得把本地算法的每次变异冒称一次大模型调用。

## 交付
可直接打开的 HTML 结果面板、可重放的逐代路径、策略源码与谱系、原始 JSONL 日志、单元测试和复现命令。GitHub 提交是代码/证据快照，不等同于 GitHub Actions 已运行。
