# RSI Puzzle Lab

八数码求解 Agent 的受约束自改进实验。独立目录、独立实验分支，不修改原 Cocos 插件，不合并 main。

## 当前进展

已冻结评估规则；已真实运行、发现并修复两个改进器调度缺陷。正式 v3 控制器正在当前会话中执行一个新的 1860 秒实验。此状态文档不是后台运行保证；最终报告将替换本段并附实际结束证据。

先看 `PROTOCOL.md`、`results/controller-repairs.md`、`results/checkpoint-controller-v2.json`。

## 概念边界

运行期使用本地受限程序合成，没有调用外部大模型，也没有修改模型权重。对话模型负责开发及根据实测反馈修复控制器。不能把每个随机变异称为一次 LLM 研究，也不能把这个演示称为开放式 RSI。

## 验收原则

同一批关卡，同样每关 900 扩展预算；独立 BFS 最优距离、路径逐步重放；固定训练/验证/最终保留集；源码及数据哈希；接受与拒绝都记录。

最终交付包含 Python 源码、测试、离线 HTML 面板、每代真实路径、候选原始日志和复现说明。GitHub 提交只表示代码/证据已保存，不表示 GitHub Actions 已运行。
